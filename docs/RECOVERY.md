# Recovered portfolio

This is a separate replacement deployment restored from the original website source. The original hosting project and saved version returned NOT_FOUND through the Sites tools, and its URL returned HTTP 404. No explanation for the missing project was available.

The original checkout, source ZIP and deployment archive have been preserved. This replacement uses a fresh database and media bucket. It restores the factual starting profile, experience, original workbook challenges, original private project templates and the website case study. Later edits, uploaded files, contact messages or admin account state stored only in the unavailable original hosted database have not been recovered.

Keep this replacement owner-private until the owning user visits /admin and activates the workspace. Admin identity is scoped to each Site and must be established again. Only after that activation is it safe to make this replacement public.
